# 德州扑克（网页多人版）

2 到 6 个人各用自己的手机、平板或电脑，在浏览器里一起玩。人不够的话，可以加电脑玩家补位，一个人也能练。

有两种用法：

- **Railway（异地联机）**：已经部署在 Railway 上，大家在不同地方各自打开同一个网址就能玩。
- **局域网**：在自己电脑上运行，大家连同一个 Wi-Fi。

两种用法是同一套文件。服务器只用 Python 自带的功能，不需要安装任何第三方包。

## 用法一：Railway

这份代码放在 GitHub 仓库 `zy090328-web/tank-duel` 的 `holdem` 分支上。Railway 里的服务跟着这个分支，往这个分支推送新代码就会自动重新部署。坦克游戏用的是 `main` 分支，两者互不影响。

- 启动命令：`python server.py`。端口用 Railway 给的 `PORT`。
- 环境变量 `ROOM_CODE` 是房间口令。改口令就在 Railway 的服务里打开 Variables 修改，保存后服务会自动重启。
- 牌局只保存在内存里。服务重启或重新部署之后，牌局会清空，大家重新加入就行。
- 服务开了休眠：大约 10 分钟没人连接就会睡着，下次打开要等几秒钟才能醒。打牌时网页一直在和服务器通信，不会中途休眠。

## 用法二：局域网

1. 安装 Python 3（3.7 或更新的版本）。
   - Windows：从 python.org 安装，安装时勾选 “Add python.exe to PATH”。
   - Mac：在终端输入 `python3 --version`，如果提示安装开发者工具，就按提示安装。
2. 在这个文件夹里打开终端，运行服务器。
   - Windows：`python server.py`
   - Mac：`python3 server.py`
3. 终端会显示一个地址，比如 `http://192.168.1.23:8000`。如果系统弹出防火墙提示，选“允许”，网络类型选专用网络。
4. 同一个 Wi-Fi 下的设备用浏览器打开这个地址。注意开头是 `http://`，不是 `https://`。

想在局域网里也要求口令的话，先设好环境变量 `ROOM_CODE` 再运行服务器。比如 Mac 上用 `ROOM_CODE=ace99 python3 server.py`。

## 开局

第一个加入的人是房主。房主在大厅里可以做下面这些事。

**加电脑玩家**，分三档：
- 新手：跟注很松，很少加注。
- 普通：按胜率和底池赔率打，偶尔诈唬。
- 高手：会统计每个对手翻牌前的入池率和加注率，用来推测对方的牌力范围。

**选模式**，分两种：
- 现金局：盲注不变。输光了可以补码，误点了可以撤销，中途可以加人或加电脑。
- 比赛：不能补码，也不能撤销。盲注按级别上涨，第 3 级起每人每手交前注。打到只剩一个人，最后排出名次。

**行动时间**：可以不限时，也可以选 20、30 或 45 秒。限时的话，每人另有 60 秒时间银行。时间用完会自动过牌或弃牌，每手结束 7 秒后自动开始下一手。

**全下后跑两次**：打开后，全下的人可以选跑两次。剩下的公共牌发两遍，每个底池两遍各分一半。要所有全下的人都同意才会跑两次。

## 牌桌上

- 轮到你时，你那一栏的上沿会亮起，同时有提示音；手机支持的话还会震动。
- 底牌只显示在你自己的屏幕上。点一下可以遮住，再点一下翻开。
- 摊牌时，赢家必须亮牌，输家自动盖牌。每手结束后，发过牌的人都可以选择亮牌。
- 刷新网页、手机锁屏或者断网之后，再打开会自动回到原来的座位。
- 如果轮到某人时他掉线了，不限时的情况下等约一分钟，限时的情况下等约 40 秒，然后自动替他过牌或弃牌。
- 菜单里可以看本手记录、上一手、比赛名次和规则。房主还可以在菜单里重新开局、回到大厅，或者移出电脑玩家和掉线的玩家。

## 说明

- 发牌、比牌、结算和电脑玩家的决策都在服务器上完成。每台设备只会收到自己的底牌，查看网页源码也看不到别人的牌。
- 人数上限是 `server.py` 开头的 `MAX_PLAYERS = 6`。
